    Développeurs API Paiement

    Encaissez depuis votre propre site.

    Quelques lignes de code : vos clients paient sur la page mepaye, l’argent arrive dans votre wallet.

    Créer ma clé API Lire la documentation

    Dans le menu Développeur, en un clic. Gardez-la côté serveur, jamais dans le navigateur.

    checkout.js 
    // 1. Votre clé, créée dans le menu Développeur
const key = process.env.MEPAYE_API_KEY;
 
// 2. Créer le paiement
const res = await fetch("https://mepaye.com/api/v1/payments", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${key}`,
    "Idempotency-Key": order.id,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 14900,
    currency: "XOF",
    externalReference: order.id,
  }),
});
 
// 3. Rediriger l’acheteur vers la page de paiement
const { payment_url } = await res.json();
redirect(payment_url);
    // 1. Votre clé, créée dans le menu Développeur
$key = getenv("MEPAYE_API_KEY");
 
// 2. Créer le paiement
$res = wp_remote_post("https://mepaye.com/api/v1/payments", [
  "headers" => [
    "Authorization"   => "Bearer " . $key,
    "Idempotency-Key" => $order_id,
    "Content-Type"    => "application/json",
  ],
  "body" => wp_json_encode([
    "amount"            => 14900,
    "currency"          => "XOF",
    "externalReference" => $order_id,
  ]),
]);
 
// 3. Rediriger l’acheteur vers la page de paiement
$payment = json_decode(wp_remote_retrieve_body($res));
wp_redirect($payment->payment_url);
