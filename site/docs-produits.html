Autre API

API Paiement

Pour encaisser via pay.mepaye.com. Menu Développeur, payments:write, KYC requis.

URL de base : https://mepaye.com/api/v1. Toutes les ressources sont en lecture seule (verbe GET uniquement) et limitées à votre boutique : une clé ne voit jamais les données d’une autre boutique.

Champs en snake_case, dates en ISO 8601 UTC, montants en minor units (voir Format). Si vous gérez plusieurs boutiques, précisez laquelle avec l’en-tête X-Store-Id. Le format est aligné sur celui de Chariow.

Authentification

Créez une clé en lecture seule dans le menu Clés API. Aucune vérification d’identité n’est requise. Chaque requête porte l’en-tête :

HTTP
Authorization: Bearer mp_live_xxxxxxxx
# ou : X-Api-Key: mp_live_xxxxxxxx

Chaque clé porte une liste de scopes. Chaque endpoint exige le sien :

ScopeDonne accès à
store:readLa boutique
products:readLes produits
sales:readLes ventes
customers:readLes clients
discounts:readLes codes promo
licenses:readLes clés de licence

Limite : 100 requêtes par minute et par clé (en-têtes X-RateLimit-Remaining et X-RateLimit-Reset, puis 429 avec Retry-After).

Gardez la clé côté serveur.

Format des réponses

Chaque réponse est une enveloppe identique :

JSON
{
  "message": "success",
  "data": { /* un objet, ou { data: [...], pagination: {...} } pour les listes */ },
  "errors": []
}

Pagination par curseur

Les listes renvoient data.data (les éléments) et data.pagination. Réglez la taille avec per_page (20 par défaut, 100 au plus) et avancez avec cursor.

{
  "message": "success",
  "data": {
    "data": [ /* … les éléments de la page … */ ],
    "pagination": {
      "next_cursor": "cmp6ljlhl0066jrmw33nbddkz",
      "prev_cursor": null,
      "has_more": true
    }
  },
  "errors": []
}
# Page 1
curl -H "Authorization: Bearer mp_live_xxx" \
  "https://mepaye.com/api/v1/sales?per_page=50"
# → data.pagination.next_cursor = "cmqxshpz5001ojr40e071659h", has_more = true

# Page suivante : repassez le next_cursor reçu
curl -H "Authorization: Bearer mp_live_xxx" \
  "https://mepaye.com/api/v1/sales?per_page=50&cursor=cmqxshpz5001ojr40e071659h"
# Bouclez tant que has_more === true.

Sur la dernière page, next_cursor vaut null et has_more vaut false.

Montants en minor units

Tous les montants sont des entiers dans la plus petite unité de leur devise : aucune décimale dans value, donc aucune erreur d’arrondi. Les champs formatted et short servent à l’affichage.

JSON
"current_price": {
  "value": 25000,          // entier en minor units
  "formatted": "25 000 XOF",
  "short": "25000",
  "currency": "XOF"
}
// XOF/XAF/GNF/CDF (0 décimale) : value = unité entière → 25000 = 25 000 FCFA
// EUR/USD (2 décimales) : value = centimes → 2599 = 25,99 €

Discounts

GET/api/v1/discounts

GET/api/v1/discounts/{id}

Les codes promo. Scope discounts:read. Filtre : search (code). Identifiant préfixé dis_.

curl -H "Authorization: Bearer mp_live_xxx" \
  "https://mepaye.com/api/v1/discounts"
{
  "id": "dis_cmqzbw3rk0001jr2i6hl2zyf6",
  "code": "BIENVENUE25",
  "type": "percentage",   // ou "fixed" (montant en minor units)
  "value": 25,            // 25 = -25 % · pour "fixed" : minor units
  "is_active": true,
  "expires_at": null,
  "max_uses": 100,
  "used_count": 3,
  "min_order_xof_cents": null,
  "created_at": "2026-06-29T14:44:00.656Z"
}

type: "percentage" : value est un pourcentage, de 0 à 100. type: "fixed" : value est un montant en minor units.

Licenses

GET/api/v1/licenses

GET/api/v1/licenses/{id}

Les clés de licence de vos produits. Scope licenses:read. Filtre : status (available ou used). Identifiant préfixé lic_.

curl -H "Authorization: Bearer mp_live_xxx" \
  "https://mepaye.com/api/v1/licenses?status=available"
{
  "id": "lic_cmqzbw3rv0003jr2ifk5u3w72",
  "key": "XXXX-YYYY-ZZZZ-1234",
  "status": "available",   // "available" | "used"
  "product": { "id": "cmp6of1fm002cjr3rga7gq3bq", "name": "Mon logiciel", "type": "license" },
  "customer": null,        // { id (cus_*), email, name } une fois attribuée
  "used_at": null,
  "created_at": "2026-06-29T14:44:00.668Z"
}

Lecture seule. mepaye livre les clés mais n’est pas un serveur d’activation : aucune route activate, revoke ou activations. status passe de available à used dès qu’une clé est rattachée à une commande.

Codes d’erreur

Même enveloppe en cas d’erreur : message est le libellé HTTP, data est vide, errors contient des messages lisibles.

JSON
{
  "message": "Forbidden",
  "data": [],
  "errors": ["Cette clé n'a pas le scope requis (products:read)."]
}
HTTPMessageSignification
401UnauthorisedClé API manquante ou invalide (Authorization ou X-Api-Key).
403ForbiddenLa clé n’a pas le scope requis, par exemple products:read.
404Not FoundRessource introuvable, ou hors de votre boutique.
429Too Many RequestsPlus de 100 requêtes par minute pour cette clé. Voir Retry-After.

Les filtres inconnus sont ignorés plutôt que rejetés.
