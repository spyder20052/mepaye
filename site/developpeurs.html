Intégration · quelques lignes

Trois étapes, côté serveur.

Choisissez une étape, le code s’éclaire.

Gardez votre clé côté serveur, jamais dans le navigateur.

checkout.js 
// 1. Votre clé, créée dans le menu Développeur
const key = process.env.MEPAYE_API_KEY;
 
// 2. Créer le paiement
const res = await fetch("https://mepaye.com/api/v1/payments", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${key}`,
    "Idempotency-Key": order.id,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 5000,
    currency: "XOF",
    externalReference: order.id,
  }),
});
 
// 3. Rediriger l’acheteur vers la page de paiement
const { payment_url } = await res.json();
redirect(payment_url);
// 1. Votre clé, créée dans le menu Développeur
$key = getenv("MEPAYE_API_KEY");
 
// 2. Créer le paiement
$res = wp_remote_post("https://mepaye.com/api/v1/payments", [
  "headers" => [
    "Authorization"   => "Bearer " . $key,
    "Idempotency-Key" => $order_id,
    "Content-Type"    => "application/json",
  ],
  "body" => wp_json_encode([
    "amount"            => 5000,
    "currency"          => "XOF",
    "externalReference" => $order_id,
  ]),
]);
 
// 3. Rediriger l’acheteur vers la page de paiement
$payment = json_decode(wp_remote_retrieve_body($res));
wp_redirect($payment->payment_url);

Questions

Ce qu’on nous demande.

Une autre question ? Écrivez-nous.

Faut-il un site codé sur mesure ?

Non. Tout site qui peut appeler une API depuis son serveur convient, WordPress compris.

La vérification d’identité est-elle obligatoire ?

Oui pour l’API Paiement, qui encaisse de l’argent. Non pour l’API Produits, en lecture seule.

Puis-je tester sans argent réel ?

Oui. Avec une clé mp_test_, la page de paiement propose de simuler un paiement réussi ou un échec.

Combien ça coûte ?

Aucun abonnement. mepaye prélève 5 % sur chaque paiement encaissé. Voir les tarifs.
